# Conversion Sequence Patterns

> Common multi-step conversion flows with the psychology behind each step. Use as blueprints — adapt to your specific product and audience.

---

## Free → Paid Subscription

| Step | Psychology | Implementation |
|------|-----------|---------------|
| 1. Free value first | Reciprocity | Give the user something useful before asking anything |
| 2. Small commitment | Commitment/Consistency | Free account creation (email only) |
| 3. Demonstrate edge | Loss Aversion | Show what they're missing (blurred premium content) |
| 4. Social proof | Social Proof | "12,847 users joined this month" |
| 5. Scarcity (if real) | Scarcity | "Founders pricing: 73 of 100 spots remaining" |
| 6. Default to annual | Default Effect | Pre-select annual plan (better value) |
| 7. Risk reversal | Loss Aversion (inverted) | "Cancel anytime" / money-back guarantee |

**Critical:** Step 1 must deliver genuine value. If the free experience is empty, no amount of psychology fixes it.

## Landing Page → Email Capture

| Step | Psychology | Implementation |
|------|-----------|---------------|
| 1. Headline clarity | First Impressions | Value proposition in under 3 seconds |
| 2. Anchor metric | Anchoring | Lead with your strongest number |
| 3. Visual credibility | Aesthetic-Usability | Polish signals trustworthiness |
| 4. Reciprocity offer | Reciprocity | "Free guide" / "weekly insights" / "tool access" |
| 5. Minimal friction | Cognitive Load | Email field only — name can come later |
| 6. Action-oriented CTA | Commitment | "Get the Guide" not "Submit" |

**Critical:** The reciprocity offer must be genuinely valuable, not a PDF of your marketing copy.

## Onboarding → Activation

| Step | Psychology | Implementation |
|------|-----------|---------------|
| 1. Quick win | Competence (SDT) | First success within 60 seconds |
| 2. Progress indicator | Zeigarnik Effect | "Step 2 of 4" — incompleteness pulls forward |
| 3. Personalization | Autonomy (SDT) | Let them choose preferences (signals ownership) |
| 4. Social context | Relatedness (SDT) | "Join 4,200 others who..." |
| 5. Core action prompt | Variable Rewards | Guide to the action that creates the habit |

**Critical:** Don't front-load tutorials. Let users DO something, then teach as needed.

## Cart → Checkout (E-commerce)

| Step | Psychology | Implementation |
|------|-----------|---------------|
| 1. Cart summary | Recognition Over Recall | Show items clearly with images |
| 2. Urgency (if real) | Scarcity | "2 left in stock" (only if true) |
| 3. Trust signals | Authority + Social Proof | Security badges, review count, guarantee |
| 4. Transparent pricing | Fairness | All costs visible before payment step |
| 5. Guest checkout | Cognitive Load | Don't force account creation |
| 6. Default shipping | Default Effect | Pre-select standard shipping |
| 7. Post-purchase delight | Peak-End Rule | Confirmation page is a moment to build loyalty |

**Critical:** Hidden fees at checkout are the #1 cart abandonment cause. Transparency beats trickery.

## Content → Engagement Loop

| Step | Psychology | Implementation |
|------|-----------|---------------|
| 1. Curiosity gap | Information Gap Theory | Headlines that create a need to know |
| 2. Chunked content | Chunking | Scannable sections, not walls of text |
| 3. Variable content | Variable Rewards | Different content daily creates return visits |
| 4. End with action | Peak-End Rule | CTA at the end of the content, not just the top |
| 5. Related content | Information Scent | "You might also like" — keep them in the loop |

**Critical:** The content must be genuinely good. Psychology amplifies quality, it doesn't replace it.
