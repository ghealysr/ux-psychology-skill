# Page-Type Psychology Prescriptions

> For each page type, the 3-5 most impactful principles. These are suggestions, not mandates. Apply what fits the brand and context. Skip what doesn't.

---

## HOMEPAGE / LANDING PAGE

| Principle | Application | Weight |
|-----------|------------|--------|
| First Impressions | Hero must communicate value in under 3 seconds | High |
| Anchoring | Lead with your strongest metric or claim | Medium |
| Social Proof | Real numbers visible early (users, results, track record) | Medium |
| Information Scent | Clear navigation paths — user knows where to go next | High |
| Aesthetic-Usability | Visual polish earns trust before content does | Medium |

**Common mistake:** Trying to say everything above the fold. Less content, more clarity.

---

## PRICING / SUBSCRIPTION PAGE

| Principle | Application | Weight |
|-----------|------------|--------|
| Anchoring | Show premium tier first or most prominent | Medium |
| Loss Aversion | Frame around what free users miss, not just what paid users get | Low-Medium |
| Default Effect | Pre-select the recommended tier | Medium |
| Commitment/Consistency | Users who've already used free features are primed to subscribe | Medium |
| Scarcity | Only if genuinely limited (founders spots, time-limited offers) | Low |

**Common mistake:** Too many tiers. Three maximum. Two is often better.

---

## DATA DASHBOARD

| Principle | Application | Weight |
|-----------|------------|--------|
| Chunking | Group data by category, priority, or type — not one giant list | High |
| Spatial Memory | Consistent layout so returning users find things instantly | High |
| Satisficing | Highlight the single most important insight prominently | Medium |
| Recognition Over Recall | Show full context (labels, icons, timestamps) — don't make users remember | High |
| Variable Rewards | Content that updates regularly creates habit-forming return visits | Medium |

**Common mistake:** Showing everything at once. Curation beats volume. "3 key insights today" hits harder than 47 data points.

---

## ONBOARDING / SIGN-UP FLOW

| Principle | Application | Weight |
|-----------|------------|--------|
| Progressive Commitment | Small free action first, account second, payment last | High |
| Cognitive Load | One question per screen beats a long form | High |
| Zeigarnik Effect | Show progress (step 2 of 4) — incompleteness pulls them forward | Medium |
| Self-Determination | Let users choose preferences — builds ownership | Medium |
| Reciprocity | Give value before asking for information | High |

**Common mistake:** Asking for credit card before delivering any value.

---

## ABOUT / TRUST PAGE

| Principle | Application | Weight |
|-----------|------------|--------|
| Authority | Methodology transparency, data sources, team expertise | High |
| Hierarchy of Trust | This page serves users at level 2-3 (interest → confidence) | Medium |
| Liking | Personality, story, relatability — people trust people they like | Medium |
| Social Proof | Testimonials, press mentions, community size | Medium |
| Transparency | Honest about limitations, not just strengths | High |

**Common mistake:** Corporate boilerplate. This page should have personality.

---

## INTERACTIVE TOOL (Calculator, Builder, Configurator, etc.)

| Principle | Application | Weight |
|-----------|------------|--------|
| Self-Determination | User controls the experience — autonomy is the feature | High |
| Zeigarnik Effect | Partially completed work pulls users back to finish | High |
| Sunk Cost | Time invested in building = reluctance to leave | Medium |
| Completion Joy | Celebrate submission — animation, confirmation, shareable result | Medium |
| Fitts's Law | Interactive elements large and easy to target | High |

**Common mistake:** Building a tool that's powerful but confusing. Simplicity first.

---

## CONTENT / BLOG

| Principle | Application | Weight |
|-----------|------------|--------|
| Picture Superiority | Lead images for every article increase engagement | Medium |
| Information Scent | Headlines must clearly describe what the reader gets | High |
| Peak-End Rule | End articles with the strongest insight or CTA, not a whimper | Medium |
| Priming | Article topics prime users for related product features | Low |
| Chunking | Subheadings, bullet points, short paragraphs — scannable structure | High |

**Common mistake:** Writing for SEO bots instead of humans. Humans first.

---

## CHECKOUT

| Principle | Application | Weight |
|-----------|------------|--------|
| Cognitive Load | Guest checkout option; minimal form fields | High |
| Default Effect | Pre-select standard shipping; pre-check "save info" | Medium |
| Loss Aversion | Show all costs upfront — surprise fees trigger abandonment | High |
| Transparency | Total cost visible before payment step | High |
| Response Time | Progress indicator; skeleton screens for processing | Medium |

**Common mistake:** Surprise fees or forced account creation at checkout.

---

## SETTINGS / ACCOUNT

| Principle | Application | Weight |
|-----------|------------|--------|
| Recognition Over Recall | Show current settings values, not blank fields | High |
| Spatial Memory | Consistent layout across settings categories | Medium |
| Default Effect | Smart defaults so most users never need to change anything | High |
| Self-Determination | Let users control their experience — respect autonomy | Medium |
| Reversibility | Every change should be easily undone | High |

**Common mistake:** Hiding important controls in nested menus or requiring support tickets.

---

## SEARCH RESULTS

| Principle | Application | Weight |
|-----------|------------|--------|
| Information Scent | Each result must clearly preview what the user will find | High |
| Chunking | Group results by category or type; don't dump a flat list | Medium |
| Satisficing | Users pick the first good-enough result — rank matters | High |
| Proximity | Related metadata (price, rating, date) close to the title | Medium |
| Cognitive Load | Filters reduce decision fatigue — let users narrow before scanning | High |

**Common mistake:** Showing too many results without hierarchy or filtering options.

---

## CONVERSION SEQUENCE (Psychology-Driven Funnel)

The optimal sequence for converting a new visitor to a subscriber:

1. **Reciprocity** — Give free value immediately (a sample result, a free tool, useful content)
2. **Authority + Social Proof** — Establish credibility (verified track record, real numbers)
3. **Liking** — Create emotional connection (brand personality, conversational voice)
4. **Commitment** — Small free action (save a preference, create free account, use a tool)
5. **Loss Aversion** — Show what they're missing (blurred premium content, locked features)
6. **Scarcity** — Time-limited offer IF genuine (early pricing, seasonal deal)
7. **Consistency** — They've already invested time — subscribing is the natural next step

**Key rule:** This sequence happens across MULTIPLE visits, not in one session. Don't rush it. Trust is earned over days, not seconds.
