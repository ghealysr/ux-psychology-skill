# Example: Subscription Conversion Psychology Review

> Demonstrates applying psychology principles to convert free visitors into paid subscribers for a content/data platform.

## Prompt
"Design a conversion sequence for a data platform. Users land on the homepage, see a preview of today's insights, and we want them to subscribe for full access."

## Review Output

### Conversion Sequence

| Step | Principle | Implementation |
|------|-----------|---------------|
| 1. Hero impact | First Impressions + Anchoring | Lead with your strongest proof point — a verified metric, a real result, a specific number. Specificity anchors credibility before anything else registers |
| 2. Free value visible | Reciprocity | Show one real insight for free — including the reasoning behind it. Give genuine value before asking for anything |
| 3. Blurred premium content | Loss Aversion | Show 2-3 additional insights with titles and categories visible but the detail blurred. The user can see they're MISSING something specific |
| 4. Track record transparency | Authority + Social Proof | Verifiable results, publicly accessible. "Every prediction tracked. Every miss counted." Transparency is the differentiator when competitors hide behind vague claims |
| 5. Daily engagement hook | Variable Rewards + Zeigarnik Effect | An interactive tool — users start building something (a watchlist, a portfolio, a dashboard), get partial results. To see the full analysis, they need to subscribe. The incomplete state creates tension |
| 6. Limited offer | Scarcity (real) + Commitment | "Early access pricing: first 200 members lock in $9.99/mo." Only if the counter is real. Fake scarcity destroys the trust you built in step 4 |
| 7. Friction removal | Cognitive Load | "No credit card to browse. Cancel anytime." Remove every objection before it forms |

### What This Gets Right vs. Common Mistakes

| Common Pattern | Psychology Problem | Better Approach |
|----------------|-------------------|----------------|
| Everything behind a paywall | No reciprocity — nothing earned before asking | Give one genuinely useful piece of content free |
| "Subscribe for expert analysis" | Vague promise — no proof before payment | Show one real insight with full reasoning for free |
| Dense data-terminal aesthetic | No emotional connection, no personality | Brand voice and visual warmth create the Liking principle effect |
| Hidden or cherry-picked results | Destroys trust on discovery | Radical transparency — show wins AND losses |

### Anti-Patterns to Avoid

- **Don't gate everything.** If the free experience is empty, no conversion psychology fixes it
- **Don't fake the limited offer counter.** One user discovering it's fake destroys credibility across all channels
- **Don't use confirmshaming.** "No, I don't want better results" on the close button is manipulative and insulting
- **Don't autoplay video with sound.** That's not delight, that's intrusion

### Psychology Weight Note

These principles are advisory. The site's visual design, brand voice, and accessibility come first. A beautiful, trustworthy site with zero psychology tricks will outperform an ugly, manipulative site with perfect psychology every time.
