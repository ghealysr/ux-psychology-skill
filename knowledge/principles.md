# UX Psychology Principles Database

> 65 actionable principles derived from NN/g research. Each includes: definition, when it applies, and a one-line design implication. Use as reference, not checklist.

---

## 1. ATTENTION

**Selective Attention** — Users focus on one thing and miss everything else.
→ Don't rely on peripheral elements to communicate important information.

**Change Blindness** — People miss changes outside their focus area.
→ Animate or highlight changes; don't assume users notice updates.

**Banner Blindness** — Users ignore anything that looks like an ad.
→ Important content in ad-shaped containers gets skipped.

**Inattentional Blindness** — Focused users miss unexpected elements entirely.
→ Critical actions need to be in the user's expected flow, not off to the side.

---

## 2. GESTALT PRINCIPLES

**Proximity** — Elements close together are perceived as grouped.
→ Spacing IS meaning. Related items tight, unrelated items separated.

**Similarity** — Elements that look alike are perceived as related.
→ Consistent styling for similar functions; differentiate distinct actions.

**Common Region** — Items in a shared container feel like a group.
→ Cards, borders, and backgrounds create implicit relationships.

**Closure** — People complete incomplete shapes mentally.
→ Progress bars and partial reveals work because the brain fills gaps.

**Continuity** — Eyes follow lines and curves naturally.
→ Align elements along clear visual paths; don't break reading flow.

**Figure/Ground** — People separate foreground from background instantly.
→ Contrast and layering create depth; modals work because of this.

**Connectedness** — Explicit visual connections (lines, arrows) bind elements.
→ Timelines, flow diagrams, and step indicators leverage this.

**Common Fate** — Elements moving together are perceived as grouped.
→ Coordinated animations signal relationship.

---

## 3. MEMORY

**Miller's Law (7±2)** — Working memory holds ~7 chunks at once.
→ Navigation items, form fields, option lists: keep under 7 when possible.

**Chunking** — Grouped information is easier to process and remember.
→ Phone numbers, card numbers, data tables: break into digestible groups.

**Recognition Over Recall** — Showing options beats asking users to remember.
→ Dropdowns beat free text; visual menus beat text-only lists.

**Cognitive Load** — Every element demands mental processing resources.
→ Remove anything that doesn't serve the user's current task.

**Priming** — Prior exposure influences subsequent interpretation.
→ What users see first colors how they interpret everything after.

**Peak-End Rule** — Experiences are judged by their peak moment and ending.
→ Invest in the best moment and the last moment of any flow.

**Spatial Memory** — Users remember where things are on screen.
→ Don't move navigation, key actions, or content between visits.

**Picture Superiority** — Images are remembered better than words.
→ Key concepts benefit from visual representation, not just text.

**Zeigarnik Effect** — Unfinished tasks nag at the mind more than completed ones.
→ Progress indicators and incomplete states pull users back.

**Power Law of Learning** — Improvement is steep early, then plateaus.
→ First-time experiences matter most; invest heavily in onboarding.

---

## 4. SENSEMAKING

**Mental Models** — Users approach interfaces with pre-existing expectations.
→ Match common patterns before innovating; innovation needs onboarding.

**Information Scent** — Users follow links that smell like what they want.
→ Link text and labels must clearly describe the destination.

**Information Foraging** — Users assess cost vs. reward before clicking.
→ If the path to value looks expensive (many clicks, forms), users bail.

---

## 5. DECISION MAKING

**Hick's Law** — More choices = longer decision time.
→ Reduce options to essentials; use progressive disclosure for the rest.

**Satisficing** — Users pick the first acceptable option, not the best one.
→ Put your best option where they'll see it first.

**Loss Aversion** — Losing something hurts ~2x more than gaining it.
→ Frame around what they'll miss, not just what they'll gain.

**Anchoring** — The first number seen sets the reference point for everything after.
→ Show the high-value metric or price first; everything else is judged against it.

**Default Effect** — Most users never change defaults.
→ Set defaults to the best outcome for the user, not for you.

---

## 6. MOTOR PROCESSES

**Fitts's Law** — Larger, closer targets are faster and easier to click.
→ Primary CTAs should be large and near the user's current focus.

**Response Time Thresholds** — 0.1s feels instant, 1s feels responsive, 10s loses attention.
→ Skeleton screens for anything over 1s; progress indication for anything over 3s.

**Interaction Cost** — Every click, scroll, and keypress is a cost.
→ Minimize steps to complete any action; every extra step loses users.

---

## 7. MOTIVATION

**Self-Determination Theory** — People need autonomy, competence, and relatedness.
→ Let users choose (autonomy), help them succeed (competence), connect them to others (relatedness).

**Fresh Start Effect** — New time periods motivate new commitments.
→ Monday, first of the month, new season: optimal moments for sign-up prompts.

**Intrinsic vs. Extrinsic** — Internal motivation outlasts rewards.
→ Build products people want to use, not products that bribe usage.

**Variable Rewards** — Unpredictable rewards are more engaging than predictable ones.
→ Content that varies daily (new data, updated recommendations, fresh insights) creates habit loops.

---

## 8. COGNITIVE BIASES

**Confirmation Bias** — People seek information that confirms existing beliefs.
→ Present balanced information; highlight unexpected wins to build trust.

**Anchoring Bias** — First information disproportionately influences judgment.
→ Lead with your strongest stat, best testimonial, or highest-value offering.

**Availability Heuristic** — Recent or vivid events feel more common.
→ Recent wins displayed prominently make your track record feel stronger.

**Negativity Bias** — Negative experiences weigh heavier than positive ones.
→ One bad experience can erase ten good ones; invest in error prevention.

**Halo Effect** — One positive attribute colors perception of everything else.
→ Beautiful design makes content feel more credible.

**False Consensus** — Designers assume users think like they do.
→ Test with real users; your intuition about "obvious" is usually wrong.

**Framing Effect** — How information is presented changes interpretation.
→ "93% uptime" vs. "7 hours of downtime per month" — same data, different impact.

**Functional Fixedness** — People get stuck on familiar solutions.
→ Innovative interfaces need gentle onboarding to break mental models.

**Sunk Cost** — Time invested makes people reluctant to leave.
→ Users who've customized a dashboard, saved preferences, or built a collection feel invested.

**Endowment Effect** — People overvalue what they already have.
→ Free trials work because giving something then taking it away feels like loss.

---

## 9. PERSUASION & TRUST

**Reciprocity** — Give something valuable before asking for anything.
→ Free tools, free content, free trials: earn trust before requesting payment.

**Social Proof** — People follow what others do, especially in uncertainty.
→ Real numbers (active users, projects completed, results delivered) outperform vague claims.

**Scarcity** — Limited availability increases perceived value.
→ Only use when genuinely scarce (founders spots, seasonal offers). Never fake it.

**Authority** — Expertise signals increase trust.
→ Track records, methodology transparency, data sources build credibility.

**Liking** — People are persuaded by those they relate to.
→ Character personality, conversational tone, and shared identity increase connection.

**Commitment/Consistency** — Small commitments lead to larger ones.
→ Free account → explore features → save preferences → subscribe. Each step feels natural.

**Prominence-Interpretation** — Users notice something, then judge it.
→ If they don't see it, they can't trust it. Make credibility signals visible.

**Hierarchy of Trust** — Trust builds through 5 levels: baseline → interest → confidence → trust → loyalty.
→ Don't ask for the sale at level 1. Earn each level sequentially.

**Creepiness-Convenience** — Personalization has a boundary.
→ Helpful recommendations: good. "We noticed you've been struggling lately": creepy.

---

## 10. EMOTION & DELIGHT

**Three Processing Levels** — Visceral (instant gut), Behavioral (usability), Reflective (meaning).
→ Design must work at all three: looks good, works well, means something.

**Aesthetic-Usability Effect** — Beautiful things feel easier to use.
→ Visual polish isn't vanity — it literally improves perceived usability.

**Delight** — Surface delight (micro-animations, surprises) and deep delight (completing a goal effortlessly).
→ Deep delight > surface delight. But both matter.

**First Impressions** — Formed in 50ms and color all subsequent experience.
→ The first screen must earn trust instantly. No second chances.

**ELIZA Effect** — People attribute personality to systems that respond conversationally.
→ Conversational interfaces create emotional connection — users engage more deeply when a system feels like it has personality.

**Completion Joy** — Finishing a task feels rewarding on its own.
→ Celebrate completions (form submitted, order confirmed, goal reached) — don't just move on.

---

## 11. ETHICS BOUNDARY

**Persuasion vs. Manipulation** — Persuasion respects user autonomy; manipulation removes it.
→ Every technique above has a bright line. Stay on the persuasion side.

**Transparency** — Users should understand what they're agreeing to.
→ Clear pricing, honest records, visible terms. No surprises.

**Reversibility** — Users should be able to undo decisions easily.
→ Easy unsubscribe, easy settings change, no punitive cancellation flows.
