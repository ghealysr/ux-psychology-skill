# Example: Sports Prediction Subscription Psychology Review

> Real-world application from the Buzzy Bets project — a sports prediction platform converting free visitors to paid subscribers.

## Prompt
"Design a conversion sequence for a sports prediction website. Users land on the homepage, see today's picks, and we want them to subscribe for full access."

## Review Output

### Conversion Sequence

| Step | Principle | Implementation |
|------|-----------|---------------|
| 1. Hero impact | First Impressions + Anchoring | Lead with the verified win rate (e.g., "64.9% across 2,847 predictions"). The number anchors credibility before anything else registers |
| 2. Free pick visible | Reciprocity | Show one real pick for free — including the reasoning. Give genuine value before asking for anything |
| 3. Blurred premium picks | Loss Aversion | Show 2-3 additional picks with the team names and confidence level visible but the actual pick blurred. The user can see they're MISSING something specific |
| 4. Track record transparency | Authority + Social Proof | Full win-loss record, publicly verifiable. "Every pick tracked. Every loss counted." Transparency IS the differentiator in an industry full of fake records |
| 5. Daily ritual hook | Variable Rewards + Zeigarnik Effect | The lineup builder — users build their own card, get a partial score. To see the full analysis, they need to subscribe. The incomplete card creates tension |
| 6. Founders pricing | Scarcity (real) + Commitment | "First 100 members lock in $9.99/mo forever." Only if the counter is real. Fake scarcity destroys the trust you built in step 4 |
| 7. Friction removal | Cognitive Load | "No credit card to browse. Cancel anytime." Remove every objection before it forms |

### What This Gets Right vs. Competitors

| Competitor Pattern | Psychology Problem | Our Answer |
|-------------------|-------------------|------------|
| 47 "best bets" behind paywall | Choice overload — users don't know which matters | Curate to 3-5 picks. Scarcity of selection creates perceived value |
| "Subscribe for expert analysis" | Vague promise — no proof before payment | Show one real pick with full reasoning for free |
| Dark mode data terminal design | No emotional connection, no personality | Character-driven brand creates Liking principle effect |
| Hidden or fake track records | Destroys trust instantly | Radical transparency is the product |

### Anti-Patterns to Avoid

- **Don't gate everything.** If the free experience is empty, no conversion psychology fixes it
- **Don't fake the founders counter.** One user discovering it's fake destroys credibility across all channels
- **Don't use confirmshaming.** "No, I don't want to win" on the close button is manipulative and insulting
- **Don't autoplay Buzzy videos with sound.** That's not delight, that's assault

### Psychology Weight Note

These principles are advisory. The site's visual design, brand voice, and accessibility come first. A beautiful, trustworthy site with zero psychology tricks will outperform an ugly, manipulative site with perfect psychology every time.
